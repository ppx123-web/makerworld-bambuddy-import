# Privacy policy for MakerWorld to Bambuddy

The extension transfers a print profile from the MakerWorld page you choose to the Bambuddy server you configure. It does not operate a separate collection or analytics server.

The extension stores your Bambuddy server address and the most recent transfer status locally in Chrome. On your request, it reads the Bambuddy authentication token from an open, logged-in tab for that configured server; it uses that token only to upload the selected 3MF file to that server and does not store it in extension storage. It temporarily observes the selected tab's MakerWorld download request to retrieve the 3MF and sends that file to the configured Bambuddy server. The MakerWorld site and your Bambuddy server handle these requests under their own policies. If you configure an HTTP address, the upload and authentication token travel without transport encryption. Use HTTPS when available.

The extension does not sell user data or use it for advertising. Removing the extension removes its locally stored settings. Your browser's normal downloads and files already uploaded to Bambuddy are managed separately.
